================================================================
  IS Risk Analyzer - интеллектуальный анализ рисков ИБ
================================================================

Веб-приложение для оценки рисков информационной безопасности
с использованием ансамбля нечётких деревьев решений.


----------------------------------------------------------------
1. ЧТО УМЕЕТ ПРИЛОЖЕНИЕ
----------------------------------------------------------------

- Генерировать синтетический датасет или загружать свой CSV/XLSX.
- Обучать ансамбль нечётких деревьев (fuzzytree) и прогнозировать
  вероятность реализации рисков.
- Считать совокупный риск (вероятность × ущерб) с учётом
  экспертных весов (числовой или лингвистический режим).
- Формировать рекомендации по обработке рисков.
- Строить 12 аналитических графиков и суррогатное дерево
  с фильтрами по отделу, типу события и уровню риска.
- Скачивать результаты: отчёт (CSV / HTML / PDF),
  датасет (CSV / HTML / XLSX), все графики в ZIP.

3. ТРЕБОВАНИЯ
----------------------------------------------------------------

Перед первым запуском на компьютере должны быть установлены:

- Python 3.10 или новее
  https://www.python.org/downloads/
  ВАЖНО: при установке поставьте галочку "Add Python to PATH".

- Node.js LTS (18.x или 20.x)
  https://nodejs.org/

- Интернет - только для первого запуска (нужно скачать
  Python- и Node-зависимости). Дальше приложение работает
  полностью локально.

Проверить, что всё стоит, можно в командной строке:

    python --version
    node --version
    npm --version


----------------------------------------------------------------
4. ЗАПУСК
----------------------------------------------------------------

4.1. Обычный запуск (рекомендуется)

    Двойной клик на файл "start.bat" в корне проекта.

    При первом запуске скрипт автоматически:
       - создаст виртуальное окружение Python;
       - установит зависимости бэкенда (3-5 минут);
       - установит зависимости фронтенда (2-4 минуты);
       - запустит бэкенд и фронтенд в отдельных окнах.

    После этого браузер откроется
    автоматически на http://localhost:3000

    Если браузер не открылся - перейдите по адресу вручную:
    http://localhost:3000

    При последующих запусках шаг установки пропускается.

4.2. Запуск вручную (если start.bat не работает)

    Откройте два окна командной строки.

    Окно 1 - бэкенд:

        cd backend
        venv\Scripts\activate
        uvicorn main:app --reload --port 8000

    Окно 2 - фронтенд:

        cd frontend
        npm start

    Откройте http://localhost:3000

----------------------------------------------------------------
6. КАК РАБОТАТЬ С ПРИЛОЖЕНИЕМ
----------------------------------------------------------------

6.1. Вкладка "Данные"

    - Сессия создаётся автоматически при открытии страницы.
    - Выберите режим:
        • "Сгенерировать" - синтетический датасет.
          Параметры: сценарий (сбалансированный / высокие
          риски / низкие риски) и количество записей.
        • "Загрузить файл" - свой CSV или XLSX.
    - После загрузки появится таблица предпросмотра
      с пагинацией.
    - Можно скачать датасет в CSV, HTML или XLSX.

6.2. Вкладка "Анализ"

    - Задайте количество деревьев в ансамбле (10-100).
    - Выберите режим оценки ущерба:
        • Числовой - задайте веса категорий ущерба
          (финансовый, репутационный, операционный,
          юридический, потеря данных).
        • Лингвистический - выберите качественные оценки
          по каждой категории.
    - Нажмите "Запустить анализ" и дождитесь завершения.
    - Прогресс-бар показывает текущий этап работы.

6.3. Вкладка "Результаты"

    - Метрики модели: Accuracy, F1, AUC.
    - Экспертные веса ущерба.
    - Таблица рекомендаций по обработке рисков
      с пагинацией и переходом на нужную страницу.
    - Кнопки скачивания отчёта: CSV, HTML, PDF.

6.4. Вкладка "Визуализация"

    - 11 графиков и суррогатное дерево.
    - Фильтры: отдел, тип события, уровень риска.
    - Кнопка "Скачать все графики (ZIP)".


----------------------------------------------------------------
7. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
----------------------------------------------------------------

- PDF-отчёт. На Windows WeasyPrint может требовать
  дополнительных системных библиотек (GTK). Если кнопка
  "Скачать PDF" возвращает ошибку - используйте HTML
  или CSV. Остальной функционал это не затрагивает.

- Хранилище сессий - в оперативной памяти бэкенда.
  При перезапуске сервера все сессии и результаты
  теряются.

- Количество записей ограничено 100 000. Обучение
  ансамбля из 100 деревьев на больших датасетах
  может занимать значительное время.
